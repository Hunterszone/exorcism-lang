#################### README ##############################

It now compiles your Java-style syntax directly into a cross-platform WebAssembly binary (.wasm), which runs natively via a tiny Node.js script. You no longer need runtime.cpp, raw header declarations, or any complex native Windows C++ linker chains.


#################### HOW TO COMPILE & RUN - COMMANDS ##############################

1. del /f /q *.ll *.wasm run.js              # Clear the containing output dir
2. py compiler.py 							 # Compile
3. node run.js 								 # Run the executable program
