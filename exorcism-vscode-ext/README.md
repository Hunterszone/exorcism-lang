# Exorcism Language Support

Official Visual Studio Code extension providing syntax support, file associations, and custom branding for the **Exorcism** programming language.

## Features

- **File Association**: Automatically recognizes all `.exrc` configuration and source files.
- **Custom Iconography**: Integrated high-contrast programming layout icon for the file explorer tree view.
- **Language Mode**: Registers the dedicated `Exorcism` language mode inside the IDE.

## Installation

1. Open **Visual Studio Code**.
2. Press `Ctrl+Shift+X` (or `Cmd+Shift+X` on macOS) to open the **Extensions** view.
3. Search for `Exorcism Language Support`.
4. Click **Install**.
