# Changelog

All notable changes to the Exorcism VS Code Extension will be documented in this file.

## [1.6.0]

### Added

- Added keywords documentation support.
- Added editor context menu support for `.exrc` files.

---

## [1.5.0]

### Added

- Added real-time syntax validation.
- Exorcism syntax errors are now reported directly in the VS Code editor.

---

## [1.4.0]

### Added

- Added Exorcism language icon.

---

## [1.3.0]

### Added

- Added `.exrc` file association.
- VS Code now automatically identifies `.exrc` files as Exorcism source files.

---

## [1.2.0]

### Added

- Added native `.exrc` file support.
- Added Exorcism language registration in VS Code.

---

## [1.1.0]

### Added

- Added syntax highlighting for Exorcism source code.
- Added TextMate grammar for Exorcism.
- Added highlighting for keywords, types, strings, characters, numbers, and comments.
